# F5 Plan — шаблон демонстрации для коллег

**Назначение документа:** единый сценарий показа сервиса команде (интеграторы, менеджеры, РОП, настройщики).  
**Длительность демо:** 25–40 минут (+ 10 минут Q&A).  
**Что подготовить заранее:** тестовый аккаунт, демо-проект (или стартовый пакет), доступ в amoCRM (опционально), пример брифа клиента.

---

## 1. Для чего сервис

**F5 Plan** — внутренний инструмент подготовки **плана внедрения amoCRM**.

В одном проекте собирается то, что обычно размазано по заметкам, таблице и переписке:

| Без F5 Plan | С F5 Plan |
|-------------|-----------|
| Бриф в чате / Word | Карточка проекта с брифом и документами |
| Воронки «на словах» | Воронки + этапы + автозадачи + результаты + виджеты |
| Поля CRM в Excel | Структурированные поля СКК (сделки / контакты / компании) |
| Список интеграций в голове | Каталог виджетов F5 + комментарии к сценарию |
| Схема на доске Miro отдельно | Доска воронки + публичная ссылка для клиента |
| ТЗ руками | Экспорт в DOCX / XLSX / Google Docs |

**Кому нужен:** сотрудники компании-интегратора, которые готовят и согласовывают план внедрения с клиентом.

---

## 2. Какие задачи решает

1. **Зафиксировать бриф клиента** — компания, сфера, сотрудники, текущие сервисы, задачи, сайт, ссылка на сделку.
2. **Спроектировать воронки** — этапы, роли (обычный / успех / отказ), автозадачи, результаты переходов, запуск виджетов.
3. **Описать поля СКК** — тип, обязательность, где показывать, варианты списков, этап заполнения.
4. **Запланировать интеграции и виджеты F5** — что подключаем и зачем (сценарий в комментарии).
5. **Собрать этапы работ и лицензию** — состав внедрения и лицензия amoCRM.
6. **Показать схему клиенту** — доска воронки, публичная ссылка, комментарии клиента.
7. **Ускорить подготовку через ИИ** — чат по проекту, генерация из брифа, аудит amoCRM.
8. **Выгрузить готовый план** — DOCX, XLSX, Google Docs / Sheets для согласования и передачи настройщику.

## 3. Основные пункты для показа (структура демо)

### Блок A. Обзор продукта (3–5 мин)

- [ ] Главная: список проектов, статусы
- [ ] Зачем один проект = один клиент / план внедрения
- [ ] Навигация проекта: карточка → доска проекта → ИИ-чат → документы

### Блок B. Создание и бриф (5 мин)

- [ ] **Создать проект** (или из стартового пакета)
- [ ] Поля брифа: название компании, сайт, сфера бизнеса, сотрудники, текущие сервисы, задачи клиента
- [ ] Загрузка брифа / документов → генерация плана / этапов работ (если используете)
- [ ] Редакторы проекта: кто может править

### Блок C. Воронки и доска (10–12 мин) — ключевой блок

- [ ] Раздел **Воронки**: добавить воронку вручную или из **библиотеки**
- [ ] Настройка этапов: название, автозадача, комментарий, цвет, роль
- [ ] **Результаты** этапа: куда уходит сделка, комментарий к стрелке
- [ ] **Запускает виджет** + **комментарий к виджету** (на доске под чипом на стрелке)
- [ ] Кнопка **Доска**: визуальная схема, стрелки, виджеты на доске
- [ ] Публичная ссылка на доску (для клиента), комментарии с доски

### Блок D. СКК, интеграции, этапы работ (7–8 мин)

- [ ] **СКК**: сделки / контакты / компании — тип поля, обязательность, отображение, варианты
- [ ] Поле из библиотеки СКК
- [ ] **Интеграции и виджеты**: выбор из каталога F5, комментарий к сценарию
- [ ] **Лицензия amoCRM**
- [ ] **Этапы работ**: состав и стоимость внедрения

### Блок E. ИИ и amoCRM (5–7 мин, по возможности)

- [ ] **ИИ-чат**: вопрос по проекту → предложения → применить / откатить
- [ ] Подключение amoCRM: импорт воронок, **AI-аудит**, продолжение в ИИ-чате
- [ ] Экспорт аудита / отчёта

### Блок F. Выгрузка и передача (3 мин)

- [ ] Экспорт **DOCX** / **XLSX**
- [ ] Экспорт в **Google Docs / Sheets**, раздел **Документы**
- [ ] Кому отдаём результат: клиент на согласование / настройщик на внедрение

## 4. Как работать с проектом (пошагово для команды)

### Шаг 1. Создать проект

1. Главная → **Создать проект**
2. Заполнить бриф (минимум: компания + сфера + задачи клиента)
3. При наличии — выбрать **стартовый пакет** отрасли
4. Сохранить → открывается карточка проекта

### Шаг 2. Заполнить каркас плана

Рекомендуемый порядок:

1. **Воронки** — этапы продаж и логика переходов  
2. **СКК** — какие поля нужны в сделках / контактах / компаниях  
3. **Интеграции и виджеты** — что подключаем и сценарии  
4. **Этапы работ** + **лицензия** — объём и коммерция внедрения  

Можно параллельно: библиотека воронок / полей СКК ускоряет типовые проекты.

### Шаг 3. Детализировать воронку на доске

1. В карточке воронки → **Доска**
2. Расставить этапы, настроить результаты и виджеты
3. Добавить комментарии к виджетам (сценарий на стрелке)
4. При необходимости — публичная ссылка для клиента и сбор комментариев

### Шаг 4. Ускорить через ИИ (опционально)

1. Открыть **ИИ-чат** проекта  
2. Запросить воронку / поля / доработку по брифу  
3. Проверить предложения → **Применить** нужное  
4. При подключённом amoCRM — аудит и разбор в чате  

### Шаг 5. Согласовать и выгрузить

1. Показать клиенту доску / карточку  
2. Внести правки по комментариям  
3. **Сохранить в DOCX / XLSX** или Google Docs  
4. Передать настройщику как рабочее ТЗ

## 7. Типовые вопросы и ответы

**Чем это лучше Notion / Miro / Excel?**  
Всё заточено под план внедрения amoCRM: воронки, СКК, виджеты F5, доска, экспорт в формат для настройщика.

**Клиент будет работать в системе?**  
Основной пользователь — команда интегратора. Клиенту можно дать публичную доску с комментариями.

**ИИ заменяет менеджера?**  
Нет. ИИ ускоряет черновик; проверка и согласование — на человеке.

**Можно ли шаблоны?**  
Да: стартовые пакеты, библиотека воронок и полей СКК.

**Как передать в работу?**  
Экспорт DOCX/XLSX/Google + доступ редакторам проекта.
